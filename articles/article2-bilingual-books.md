# 用 AI Agent 制作你自己的双语对照电子书

> 这是系列文章的第二篇。[上一篇](article1-mcp-tokindle.md)介绍了怎么用 MCP 工具一键把网上文章导入 Kindle。这一篇讲一个更进阶的玩法：**做双语书**。

## 为什么要双语对照

学英语最好的方式之一，就是读原版书。但直接读英文原版，遇到生词就要查字典，阅读节奏被反复打断，读着读着就放弃了。

纯中译版解决了理解问题，但又丢失了原版的语言质感——那些微妙的用词、句式节奏、双关语，翻译过程中总会打折扣。

**最好的方案是双语对照**：一段英文，一段中文。遇到看不懂的地方，扫一眼中文翻译即可，不用查字典；想品味原文的时候，英文就在上面。

互联网上找一本英文 EPUB 不难，找一本中文 EPUB 也不难。但找一本**已经做好段落对齐的双语对照版**？几乎不存在。

## 赚钱的方法网上都有人教，双语对照怎么就没人做？

因为段落对齐这件事，比想象的复杂得多：

1. **中英文章节数可能不一样**：英文版有 42 章，中文版可能拆成了 50 章
2. **段落切分方式不同**：英文用空行分段，中文版可能用了缩进
3. **翻译可能合并/拆分段落**：英文一段的内容，中文版拆成了两段
4. **还有序言、注释、目录等干扰内容**

纯靠脚本按段落序号硬对齐，效果惨不忍睹。而手动对齐一本 300 页的书？没人有这个耐心。

## 我的方案：AI Agent + 自动化脚本

我的思路是：**脚本负责提取和初步对齐，AI 负责智能匹配和校对**。

整个流程封装在 `merge_books` 这个 Skill 里，配合 Hermes Agent 使用。

### 整体流程

```
英文 EPUB ──┐               ┌── 中英对照 Markdown ──▶ EPUB/KFX
            │  章节拆分      │
            ├──▶ 段落对齐 ──▶│  （CET 词汇标注）
            │                │
中文 EPUB ──┘               └── 推送到 Kindle
```

### Step 1：拆分章节

脚本把英文和中文 EPUB 分别拆成章节级 Markdown 文件：

```bash
python skills/merge_books/scripts/extract_chapters.py \
  --en "Atomic Habits.epub" \
  --zh "掌控习惯.epub" \
  --out book_chapters/
```

输出目录结构：

```
book_chapters/
├── markdown/
│   ├── en/          # 英文章节
│   │   ├── 01.md
│   │   ├── 02.md
│   │   └── ...
│   └── zh/          # 中文章节
│       ├── 01.md
│       ├── 02.md
│       └── ...
```

这一步你会看到两边的章节数量和标题，人工确认一下对应关系。

### Step 2：AI 段落对齐

这是核心步骤。你跟 Hermes Agent 说：

> 我：帮我合并 book_chapters/markdown/ 下的第 3 章中英文，做段落对齐

Agent 会：
1. 读取英文第 3 章和中文第 3 章
2. 按段落切分
3. 根据内容语义（不只是长度）做段落配对
4. 如果一段英文对应中文两段（或反过来），智能合并
5. 输出中英交替的 Markdown

效果类似：

```markdown
**English:**
The most effective way to change your habits is to focus not on what you 
want to achieve, but on who you wish to become.

**中文:**
改变习惯最有效的方法，不是关注你想要达到的目标，而是关注你想成为什么样的人。

---

*Notes: effective (CET-4 有效的), achieve (CET-4 达到), become (CET-4 成为)*
```

### Step 3：词汇标注

双语对照的一个额外价值是**词汇学习**。脚本会自动标注 CET-4 和 CET-6 范围内的生词：

```markdown
Your identity emerges out of your *endeavors* (CET-6 努力/奋斗).
```

阅读时遇到带标注的词，一眼就能看到词义和级别，不需要额外查字典。

### Step 4：生成电子书并推送

所有章节合并完成后，生成最终的 Markdown 文件，然后用第一篇介绍的 MCP 工具转成 EPUB/KFX：

> 我：把 merged_book.md 转成 KFX 并推送到 Kindle

Agent 自动完成格式转换和推送。

## 实际效果

我拿《Atomic Habits》的中英文版做了一次完整测试：

- 英文版 42 章，中文版 42 章，章节一一对应
- 全书约 1200 个段落，AI 对齐准确率约 95%
- 少量段落需要手动微调（主要是翻译时合并了原文的多段）
- 最终输出 EPUB 约 800KB，KFX 约 1.2MB
- 在 Kindle 上阅读体验非常好：英文段落下面紧跟中文翻译，CET-6 词汇带标注

**最爽的是**：整个过程中，你只需要跟 Agent 对话，告诉它文件在哪、要做什么。拆分、对齐、标注、转换、推送——全是自动的。

## 适合做什么书

| 适合 | 不太适合 |
|------|---------|
| 非虚构类（自助、商业、科普） | 诗歌（韵律无法对齐） |
| 段落分明的小说 | 教材（公式太多，排版复杂） |
| 英文原版 + 优质中译版 | 中译版质量太差的书 |
| 章节结构中英文一致 | 中英文章节差异大的版本 |

## 一些技巧

### 章节不对齐怎么办？

英文版和中文版的章节划分偶尔会不一样（比如英文版把两章合成了一章）。这时候可以：

1. 先跑拆分脚本看两边的章节列表
2. 人工确认哪些章需要合并/拆分
3. 告诉 Agent：「英文版第 5 章对应中文版第 5 和第 6 章」

### 词汇标注级别可调

默认标注 CET-4 和 CET-6。如果你的词汇量已经很大，可以只标 CET-6 或更高难度的词：

> 我：只标注 CET-6 和 GRE 级别的词汇

### 排版偏好

默认是「英文在上、中文在下」。你也可以改成「中文在前、英文在后」，或者并排显示（不过并排在 Kindle 上效果一般，不推荐）。
